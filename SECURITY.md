# Security Policy

## Supported versions

Security fixes are considered for the latest version on the default branch. Test changes in a
staging WordPress installation before production use.

## Reporting a vulnerability

Do not disclose a suspected vulnerability, provider credential or WordPress installation detail in
a public issue.

Use this repository's **Security** tab and **Report a vulnerability** option. Include the affected
version or commit, WordPress and PHP versions, impact and safe reproduction steps. Never include API
keys, passwords, customer content or other secrets.

If private reporting is unavailable, contact [Opace Digital Agency](https://opace.agency/get-in-touch)
and identify this repository. Reports are reviewed on a best-effort basis; this policy does not
create a support SLA.
