# AI Scribe: ChatGPT SEO Content Creator for WordPress

> **Opace open-source portfolio:** [Browse Opace WordPress plugins, AI tools and Agent Skills](https://github.com/OpaceDigitalAgency/OpaceDigitalAgency)

AI Scribe is an open-source WordPress content-generation plugin with a guided article workflow, editable prompts, keyword and title research, SEO metadata integration, humanisation options and AI image generation.

The repository’s WordPress plugin readme and plugin header report version `2.6`, GPL-3.0 licensing and testing through WordPress `6.8.1`.

## Features

- Guided long-form article generation
- Editable prompts and reusable prompt settings
- Keyword research and title suggestions
- Standard, humaniser and personality writing modes
- OpenAI and Anthropic model support
- AI image generation and WordPress media-library integration
- Live token and estimated-cost information
- Classic Editor and Gutenberg support
- Draft-post and shortcode output
- Yoast SEO, Rank Math, AIOSEO and SEOPress metadata integration
- Divi, Elementor and ACF-friendly shortcode workflow

## Requirements

- WordPress 4.4 or later
- A supported AI-provider account and API key
- Available provider credits; API usage may incur charges

Model availability, context limits and provider pricing change over time. Verify the current provider documentation rather than relying on historical values in the bundled WordPress readme.

## Installation

1. Download or clone this repository.
2. Place the plugin directory in `wp-content/plugins/`.
3. Activate AI Scribe in WordPress.
4. Configure the required provider keys in the plugin settings.
5. Test the workflow on a staging site before production use.

Never commit API keys to source control. Review and edit generated content before publishing.
